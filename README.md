# Todo App (할 일 관리 앱)

개인용 할 일 관리 앱. Windows, Linux, Android 환경을 지원하며, Google 로그인을 통한 기기 간 실시간 데이터 동기화 제공.

---

## ✨ 주요 기능

### 1. 할 일 & 카테고리 관리
- **카테고리(탭) 분리**: 무제한 카테고리(탭) 생성 및 용도별 할 일 목록 분리 가능
- **메모 & 하위 체크리스트**: 할 일 내 상세 메모 작성 및 복수의 하위 체크리스트 생성 지원
- **드래그 앤 드롭**: 마우스 및 터치 조작으로 카테고리 및 할 일 항목 순서 자유롭게 변경 가능
- **우선순위 지정**: 할 일 항목별 중요도(높음/중간/낮음) 설정 기능

### 2. 세밀한 자동 초기화 (반복 루틴)
설정된 주기에 맞춰 완료(체크) 상태 자동 해제
- **기본 주기**: 매일, 매주, 매월, 매년 단위 초기화 지원
- **커스텀 주기**: 'N일마다', 'N주마다 특정 요일' 등 세밀한 반복 주기 설정 가능
- **항목별 개별 설정**: 앱 전역 초기화 시간과 별개로 특정 항목에만 독립적인 초기화 시간/주기 지정 가능

### 3. UI 커스터마이징
- **배경화면 설정**: 전체 공통 배경 및 **카테고리(탭)별 개별 배경 이미지** 지정 가능
- **테마 & 컬러 팔레트**: 라이트/다크 모드 기본 지원. 10종의 기본 테마 및 Hex 코드 입력을 통한 커스텀 포인트 컬러 설정 기능
- **UI 숨김 모드**: 상단 아이콘(👁️) 클릭 시 UI 패널이 숨겨지며 배경화면 전체 감상 가능

### 4. 프리셋 (템플릿) 공유
- **내보내기**: 본인이 구성한 카테고리 및 할 일 목록을 6자리 공유 코드로 생성
- **가져오기**: 타인의 6자리 코드를 입력하여 해당 할 일 템플릿 즉시 복사 및 적용 가능.

### 5. 편의 및 동기화 기능
- **실시간 자동 동기화**: 모바일-PC 간 변경 사항 1초 이내 실시간 반영
- **완료 항목 자동 정렬**: 체크 완료된 항목은 목록 하단으로 자동 이동
- **실수 방지 (Undo)**: 카테고리 삭제 시 4초 내 복구 버튼(Undo) 제공

## 💻 플랫폼별 특화 기능

- **데스크톱 (Windows / Linux)**
  - **항상 위 고정 (Always on Top)**: 앱 창을 최상단에 고정 가능
  - **자동 시작**: OS 로그인 시 앱 자동 실행 옵션 제공
- **모바일 (Android)**
  - OS 네이티브 시스템 알림 통합 지원

## 🛠 개발자 가이드 (Developer Guide)
<details>
<summary>개발 환경 및 빌드 명령어 보기</summary>

### 기술 스택
- **코어**: Vanilla JS (ES Modules)
- **데스크톱**: Electron 28
- **모바일**: Capacitor 6
- **데이터베이스**: Firebase Firestore (compat 10.14.1) & IndexedDB

### 환경 요구사항
- Node.js 18+
- JDK 21 (Android 빌드 시 필수)
- Android Gradle Plugin 8.7.3

### 명령어
```bash
# 의존성 설치
npm install

# 개발 모드 실행 (Electron)
npm start

# 데스크톱 빌드 (Windows EXE / Portable)
npm run dist:win
npm run dist:portable

# 모바일 빌드 (Android)
npm run android:apk
npm run android:open

# 스모크 테스트
npm run test:smoke
```
